# Claude Code 来源说明

接入 `~/.claude` 本地会话；设置中的来源目录或 `CLAUDE_SESSIONS_DIR`（路径列表）可覆盖。

- 现代 `projects/**/*.jsonl` 转录与旧版 `sessions/*.json` 同时扫描，旧版可从 `history.jsonl` 补充输入历史；相同会话 ID 优先保留现代转录。
- 用户/助手消息、Thinking、工具调用与结果统一展示；只展示本地文件实际内容，不通过 Anthropic API 补全，也不推断缺失内容。

## 注意

- Claude 本地历史可能包含提示词与源代码片段；测试样本必须完全虚构或人工脱敏，不得提交真实 `~/.claude` 数据。
- 浏览、搜索和导出不会写入来源数据；永久删除及显式启用的维护操作会在用户确认后修改对应原始记录。
