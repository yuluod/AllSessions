# ZCode 来源

只读接入 ZCode CLI 的 SQLite 聚合会话库。默认 `~/.zcode/cli/db/db.sqlite`；`ZCODE_DB` 环境变量（相对路径按 `~/.zcode/cli/` 解析）或设置中的来源目录可覆盖。

- 从 `session`、`message`、`part` 三表聚合会话，缺表即判不兼容；用户/助手文本、Thinking、工具输入/结果统一展示，子代理会话默认排除。
- 内容指纹覆盖原始行，可识别原地编辑；数据库本体及 `-wal` 变化后整源刷新。

## 不支持

永久删除原始数据与恢复会话。格式不兼容时记入来源诊断，不当作成功结果。
