# 前端组件与主题约定

## 分层与职责

同一主题内，同类组件保持一致；不同主题允许保留字体、密度、形状和材质差异。

1. `public/styles/foundation.css` 定义组件参数的默认值。
2. `public/styles/themes/*.css` 配置主题字体、颜色、圆角及组件视觉参数；主题专属的像素边框、阴影等也留在这里。
3. `public/styles/components.css` 消费参数，统一组件的结构、状态与交互反馈。
4. 页面样式负责布局、宽度和语义变体；`responsive.css` 负责断点适配。

导入顺序为基础、主题、页面、共享组件、响应式。共享文件不再重置主题参数；新增主题不需要复制组件实现。

## 主题中的体现

| 主题                | 字体方向（保留现有字体栈） | 常规／紧凑控件最小高度 | 字重 | 开关与徽章                       |
| ------------------- | -------------------------- | ---------------------- | ---- | -------------------------------- |
| 经典报表 `greenbar` | 等宽字体                   | 34／32px               | 600  | 小圆角、矩形标签                 |
| 开发者终端 `tui`    | 界面无衬线，标题与代码等宽 | 34／32px               | 650  | 圆形滑块、胶囊标签               |
| 现代青白 `standard` | 系统无衬线                 | 36／32px               | 600  | 圆形滑块、胶囊标签，保留柔和层次 |
| 高对比红白 `hdweb`  | 紧凑无衬线                 | 32／30px               | 650  | 小圆角开关、直角标签，无浮起阴影 |
| 工业警示 `blind`    | 窄体优先                   | 36／34px               | 700  | 小圆角、较大字号与行高           |
| 像素工作站 `pixel`  | 等宽字体                   | 34／32px               | 700  | 直角开关与标签、硬边框及离散反馈 |

高度是最小高度，长文案和字体回退仍可撑开控件。实际字体取决于系统已安装字体；不要为了统一字体而覆盖主题的 `--font-ui`、`--font-display` 和 `--font-mono`。`blind` 是现有主题标识，不表示通过了无障碍认证。

控件材质也由主题分别配置，并同时引用浅色／深色语义色：经典报表用纸面按钮和浅底标签；开发者终端用抬升按钮、小圆角标签；现代青白用中性边框和轻量标签；高对比红白加强直角边界；工业警示用强边框区分按钮和下沉输入区；像素工作站保留硬边框、阴影和即时反馈。普通控件悬停优先体现表面层次，选中和展开状态继续使用强调色。

## 可配置参数

- 尺寸和排版：`--control-height`、`--control-height-compact`、`--control-font-size`、`--control-font-compact`、`--control-weight`、`--control-line-height`。
- 控件外观：`--control-padding-inline`、`--control-border`、`--control-background`、`--control-hover-background`、`--control-hover-color`、`--field-background`；主题可分别调整按钮与表单的层次，明暗配色继续引用各自的语义色。
- 筛选标签：`--filter-chip-radius`、`--filter-chip-background`；默认跟随主题徽章形状，现代青白使用小圆角和下沉底色。像素主题保留直角规则。
- 分段控件：`--segment-height`、`--segment-height-compact`、`--segment-font-size`、`--segment-font-compact`。
- 开关：`--switch-width`、`--switch-height`、`--switch-thumb` 及对应的 `-compact` 参数；`--control-round`、`--control-thumb-radius` 定义开关形状。
- 徽章：`--badge-radius` 独立于开关形状，避免相互影响。
- 反馈：`--control-motion` 定义共享控件的过渡时长，像素主题为零；颜色继续使用语义色变量，边框和阴影的主题特例保留在主题文件。

紧凑容器只将常规变量映射到紧凑变量，不写死具体数值。纯图标按钮可有独立几何尺寸，以保持搜索框等布局，但必须保留可访问名称和焦点样式。

## 组件使用

- 普通操作使用 `.ghost-button`，危险执行使用 `.danger-button`；保留页面已有的危险文字按钮等语义变体。
- 在 `.ghost-button` 上用 `.button--primary` 强调当前区域主要操作，用 `.button--quiet` 降低辅助操作的边框和底色；按下／展开状态保留原有反馈。像素主题通过 `--quiet-control-border` 保留硬边界。
- 会话详情保留终端恢复、整理、收藏和信息入口；导出选项、归档和删除集中于“更多”，删除仍走原有确认流程。标题下分层展示来源、Provider、已记录用量对应的模型、时间和工作目录，属性面板保持完整。
- 阅读区通过 `--detail-title-size`、`--conversation-measure`、`--conversation-font-size` 和 `--conversation-line-height` 管理标题和正文规格；工具调用保留原有折叠与定位行为，折叠态使用紧凑行。
- 设置、正文和维护开关共用状态规则；正文使用紧凑尺寸，维护开关通过 `--switch-tone` 切换警示色。
- 明暗切换和角色切换共用分段选中态，文字版与图标版保留布局差异。
- 临时菜单使用原生 `details` 并标记 `data-popover`，统一交给 `bindPopoverMenus` 处理互斥、外部点击与 Escape。表单内部操作不会关闭当前菜单。
- 菜单入口支持方向下／上键打开并聚焦第一个／最后一个可用控件，内部表单保留原生方向键行为；Tab 移出菜单后关闭，Escape 关闭并将焦点返回入口。显示范围选项提供整行悬停、焦点和选中反馈。
- 弹窗必须绑定可访问标题，正文能够滚动；新增表单行后聚焦新输入框，关闭后回到入口。
- 简单空状态使用 `createEmptyState`，图表与列表使用紧凑变体；无数据与失败应有不同说明。

## 图标与反馈

- 图标一律使用 SVG（静态资源走 CSS mask，动态节点用 `createElementNS` 构建），不用文本字符充当图标：字符基线随回退字体漂移，无法跨主题稳定对齐。几何取自 Phosphor Icons（`viewBox="0 0 256 256"`、`fill="currentColor"`，来源与许可证见 `public/assets/icons/`）：静态节点内联 `ICON_PATHS` 同一份 path，动态节点用 `createIcon` 构建；有激活态的控件内嵌 `.icon-regular` / `.icon-fill` 两条 path，由共享规则按 `.active` / `aria-pressed` 切换。侧栏开合按钮保留手绘复合图形（含动效 caret），agent 品牌图标在 `assets/agents/`。
- 折叠披露行（来源树「其他来源」、项目「显示其余」）共用同一套规则（`.source-tree__more` / `.project-more`）：flex 行内「caret + 标签 + 计数」，标签占弹性位，`aria-expanded` 驱动旋转；计数表示未展示的数量，展开后清空。项目行只保留外边距定位差异。结构用 flex 不用 grid：grid 定宽首列会把未配套标记的裸文本匿名项压成竖排，flex 则自然退化为整行文本。列表底部的分页按钮（`.load-more-btn`）是主内容区的 ghost 按钮家族，不并入披露行。
- 复制类反馈：按钮短暂时用 `data-state="success|failed"` 着色并短暂替换为 check/cross 图标，超时还原；内联文本处可直接显示「已复制」等文字。成功用 `--success`，失败用 `--danger`，不用裸 `✓`/`×` 字符。

## 设计令牌

- 圆角只有 `--radius`（面板）、`--radius-small`（行内控件）、`--radius-large`（对话框）三档；2–4px 的微小元素（kbd、热力格、代码内联）允许字面量，装饰形状（如空态底纹）同理。999px 胶囊用 `--control-round`/`--badge-radius`。
- 层叠只用 foundation 的 `--z-*` 令牌（`--z-surface` 1 / `--z-sticky-group` 2 / 阅读区 4–9 / `--z-menu` 12 / `--z-organizer` 13 / `--z-sticky` 20 / `--z-tooltip` 40 / `--z-toast` 60），新浮层一律引用令牌并归入最近语义档，不写字面量；依附文本色的效果（如阅读态标题淡出投影）不属于 `--shadow-*`，保留字面量并注释说明。
- 开关旋钮用 `--switch-knob`（浅色默认白，各主题深色块覆写），不硬编码颜色。

## 本地化文案

- 静态节点走 `data-i18n` 声明；动态构建的固定文案同时挂 `dataset.i18n` 交给全局遍历器。随状态变化的文案（如「显示其余 N 个项目」↔「收起」）不能用静态遍历器，必须在重渲染路径中用 `t()` 赋值，语言切换由 `rerenderLocalizedContent` 覆盖。
- 文案值本身不携带图标字符（如 `✓`）；图标由组件渲染，文案只承载文字。

## 修改与验证

新增视觉差异先判断是否能用现有主题参数表达；只有组件结构或材质确实不同，才增加主题选择器。不要用 `!important` 或重复页面规则抵消共享样式。

普通文字与实际底色的对比度至少为 4.5:1；必须检查选中背景、来源徽章和危险操作，不能只验证页面底色。反色选中态需要配套前景与背景，不将反色文字单独套在沿用普通底色的徽章上。筛选菜单以整行筛选区为定位边界，验证入口换行、调整列表宽度后仍能完整显示。

修改共享组件后，检查六种主题的浅色与深色状态，覆盖会话工具栏、设置表单及弹窗。重点验证长中文／英文、字体回退、紧凑布局、键盘焦点、禁用和危险操作、菜单遮挡、滚动与窄窗口。确认主题切换后仍使用同一套菜单和键盘行为，并恢复测试前的外观设置。

运行 `pnpm test`、`pnpm lint` 和 `pnpm build`；视觉差异必须在浏览器中核对，单靠源码断言不能证明样式正确。

## 统计时间与热力图

- 顶部日期范围同时控制汇总、调用排行、趋势与相关会话。热力图的会话／Token 切换只改变着色指标，日期格点击后将活动范围设为该日。
- 数据图形（排行条、趋势柱、热力格）使用 `--chart`/`--chart-strong` 数据色，与「可交互 = `--accent`」分离；区块标题和指标数字用正文色，蓝/青只留给链接、按钮和选中态。未覆写 `--chart` 的主题自动回落到 accent 系。
- 日期格使用原生按钮及单一 Tab 入口；方向键按日／周移动，Home／End 到首尾，Enter／空格选中。重查后将焦点返回选中日期。

## 设置模块

- 外观、语言及常规偏好立即生效；来源目录单独编辑草稿，点击“保存来源设置”后才持久化并刷新。未改动时禁用保存，配置恢复模式允许无改动保存以修复损坏配置。
- 来源草稿必须复制路径数组，不能和已保存数据共享引用。关闭按钮、背景点击、Escape 和设置快捷键共用关闭保护；有未保存修改时提供继续编辑或放弃，不静默丢弃。保存失败保留草稿，保存期间不能放弃或重复提交。
- 来源卡片显示最近诊断状态和索引数量；待保存修改单独标记，不能伪装成已经生效的扫描状态。没有诊断时明确显示“尚无诊断”，不能等同于来源已停用。
- 主题参数同时应用到相应 `data-preview-theme` 元素；明暗配色取当前解析后的模式。预览复用目标主题字体、色彩、圆角及边框，不维护另一份配色表。`--preview-line-width` 和 `--preview-shadow` 只控制微型预览的材质。
