# 前端组件与主题约定

## 分层与职责

同一主题内，同类组件保持一致；不同主题允许保留字体、密度、形状和材质差异。

1. `public/styles/foundation.css` 定义组件参数的默认值。
2. `public/styles/themes/*.css` 配置主题字体、颜色、圆角及组件视觉参数；主题专属的像素边框、阴影等也留在这里。
3. `public/styles/components.css` 消费参数，统一组件的结构、状态与交互反馈。
4. 页面样式负责布局、宽度和语义变体；`responsive.css` 负责断点适配。

导入顺序为基础、主题、页面、共享组件、响应式。共享文件不再重置主题参数；新增主题不需要复制组件实现。

## 主题中的体现

| 主题                | 字体方向（保留现有字体栈） | 常规／紧凑控件最小高度 | 字重 | 开关与徽章                       |
| ------------------- | -------------------------- | ---------------------- | ---- | -------------------------------- |
| 经典报表 `greenbar` | 等宽字体                   | 34／32px               | 600  | 小圆角、矩形标签                 |
| 开发者终端 `tui`    | 界面无衬线，标题与代码等宽 | 34／32px               | 650  | 圆形滑块、胶囊标签               |
| 现代青白 `standard` | 系统无衬线                 | 36／32px               | 600  | 圆形滑块、胶囊标签，保留柔和层次 |
| 高对比红白 `hdweb`  | 紧凑无衬线                 | 32／30px               | 650  | 小圆角开关、直角标签，无浮起阴影 |
| 工业警示 `blind`    | 窄体优先                   | 36／34px               | 700  | 小圆角、较大字号与行高           |
| 像素工作站 `pixel`  | 等宽字体                   | 34／32px               | 700  | 直角开关与标签、硬边框及离散反馈 |

高度是最小高度，长文案和字体回退仍可撑开控件。实际字体取决于系统已安装字体；不要为了统一字体而覆盖主题的 `--font-ui`、`--font-display` 和 `--font-mono`。`blind` 是现有主题标识，不表示通过了无障碍认证。

## 可配置参数

- 尺寸和排版：`--control-height`、`--control-height-compact`、`--control-font-size`、`--control-font-compact`、`--control-weight`、`--control-line-height`。
- 分段控件：`--segment-height`、`--segment-height-compact`、`--segment-font-size`、`--segment-font-compact`。
- 开关：`--switch-width`、`--switch-height`、`--switch-thumb` 及对应的 `-compact` 参数；`--control-round`、`--control-thumb-radius` 定义开关形状。
- 徽章：`--badge-radius` 独立于开关形状，避免相互影响。
- 反馈：`--control-motion` 定义共享控件的过渡时长，像素主题为零；颜色继续使用语义色变量，边框和阴影的主题特例保留在主题文件。

紧凑容器只将常规变量映射到紧凑变量，不写死具体数值。纯图标按钮可有独立几何尺寸，以保持搜索框等布局，但必须保留可访问名称和焦点样式。

## 组件使用

- 普通操作使用 `.ghost-button`，危险执行使用 `.danger-button`；保留页面已有的危险文字按钮等语义变体。
- 设置、正文和维护开关共用状态规则；正文使用紧凑尺寸，维护开关通过 `--switch-tone` 切换警示色。
- 明暗切换和角色切换共用分段选中态，文字版与图标版保留布局差异。
- 临时菜单使用原生 `details` 并标记 `data-popover`，统一交给 `bindPopoverMenus` 处理互斥、外部点击与 Escape。表单内部操作不会关闭当前菜单。
- 弹窗必须绑定可访问标题，正文能够滚动；新增表单行后聚焦新输入框，关闭后回到入口。
- 简单空状态使用 `createEmptyState`，图表与列表使用紧凑变体；无数据与失败应有不同说明。

## 修改与验证

新增视觉差异先判断是否能用现有主题参数表达；只有组件结构或材质确实不同，才增加主题选择器。不要用 `!important` 或重复页面规则抵消共享样式。

普通文字与实际底色的对比度至少为 4.5:1；必须检查选中背景、来源徽章和危险操作，不能只验证页面底色。反色选中态需要配套前景与背景，不将反色文字单独套在沿用普通底色的徽章上。筛选菜单以整行筛选区为定位边界，验证入口换行、调整列表宽度后仍能完整显示。

修改共享组件后，检查六种主题的浅色与深色状态，覆盖会话工具栏、设置表单及弹窗。重点验证长中文／英文、字体回退、紧凑布局、键盘焦点、禁用和危险操作、菜单遮挡、滚动与窄窗口。确认主题切换后仍使用同一套菜单和键盘行为，并恢复测试前的外观设置。

运行 `pnpm test`、`pnpm lint` 和 `pnpm build`；视觉差异必须在浏览器中核对，单靠源码断言不能证明样式正确。

## 设置模块

- 外观、语言及常规偏好立即生效；来源目录单独编辑草稿，点击“保存来源设置”后才持久化并刷新。未改动时禁用保存，配置恢复模式允许无改动保存以修复损坏配置。
- 来源草稿必须复制路径数组，不能和已保存数据共享引用。关闭按钮、背景点击、Escape 和设置快捷键共用关闭保护；有未保存修改时提供继续编辑或放弃，不静默丢弃。保存失败保留草稿，保存期间不能放弃或重复提交。
- 来源卡片显示最近诊断状态和索引数量；待保存修改单独标记，不能伪装成已经生效的扫描状态。没有诊断时明确显示“尚无诊断”，不能等同于来源已停用。
- 主题参数同时应用到相应 `data-preview-theme` 元素；明暗配色取当前解析后的模式。预览复用目标主题字体、色彩、圆角及边框，不维护另一份配色表。`--preview-line-width` 和 `--preview-shadow` 只控制微型预览的材质。
